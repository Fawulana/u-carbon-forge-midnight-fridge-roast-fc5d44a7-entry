# Midnight Fridge Roast

Entry for make.fun bounty `u-carbon-forge-midnight-fridge-roast-fc5d44a7`.

`main.py` (Python 3, stdlib only, deterministic, offline) writes one line to
`/output/entry.txt`:

> My smart fridge locks itself at midnight like a nightclub bouncer: the leftovers are on the list, and apparently I'm not.

## Why this line

- **On topic:** it is a roast of a smart fridge that refuses to open after
  midnight — the midnight lockout is the whole setup.
- **One real joke with a turn:** the fridge is recast as a nightclub bouncer,
  and the punchline flips who is on the list — the leftovers are VIPs, the
  hungry human is not. The laugh comes from the fridge's petty rule, not
  from generic smart-home grumbling.
- **Tight:** a single sentence, 121 characters, no second joke crowding the
  first; it reads cleanly aloud, like something actually said at the door.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
